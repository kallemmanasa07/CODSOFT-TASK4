# Rock Paper Scissors Game

## Overview

The Rock Paper Scissors Game is a Python-based interactive application where the user plays against the computer. The user selects Rock, Paper, or Scissors, and the computer randomly generates its choice. The program then determines the winner based on the game rules and displays the result. An optional score-tracking feature allows users to play multiple rounds and keep track of wins and losses.

## Features

* User chooses Rock, Paper, or Scissors
* Computer generates a random choice
* Automatic winner determination
* Displays both user and computer selections
* Score tracking for multiple rounds (optional)
* Play Again functionality
* User-friendly command-line interface

## Technologies Used

* Python
* Random Module

## Objective

The objective of this project is to create an entertaining game while learning Python programming concepts such as conditional statements, loops, functions, random number generation, and user input handling.

## Game Rules

* Rock beats Scissors
* Scissors beats Paper
* Paper beats Rock
* If both players choose the same option, the game is a tie

## Execution Steps

### Prerequisites

* Python 3.x installed on your system

### Steps to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/rock-paper-scissors.git
   ```

2. Navigate to the project directory:

   ```bash
   cd rock-paper-scissors
   ```

3. Run the Python file:

   ```bash
   python rock_paper_scissors.py
   ```

4. Enter your choice:

   * Rock
   * Paper
   * Scissors

5. View the computer's choice and the game result.

6. Choose whether to play another round.

### Example

**Input:**

```text
Enter your choice (rock/paper/scissors): rock
```

**Output:**

```text
You chose: rock
Computer chose: scissors

Result: You Win!
```

## Project Workflow

1. Start the game.
2. Prompt the user to select Rock, Paper, or Scissors.
3. Generate the computer's choice randomly.
4. Compare both choices using game rules.
5. Display the winner.
6. Update scores (if enabled).
7. Ask the user whether they want to play again.
8. Repeat or exit the game.

* Working with conditional statements (`if-elif-else`)
* Using loops for repeated gameplay
* Managing user input and validation
* Implementing game logic and score tracking
